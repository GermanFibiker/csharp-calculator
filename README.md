# C# Calculator

Консольный калькулятор на C#.

## Возможности

- ➕ Сложение
- ➖ Вычитание
- ✖️ Умножение
- ➗ Деление
- ❌ Защита от деления на ноль
- 🔄 Повторное использование без перезапуска

## Технологии

- C#
- .NET
- Console Application
